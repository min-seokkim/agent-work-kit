# Agent Work Kit

[English](README.md) | 한국어

Agent Work Kit은 Claude Code, Codex 같은 코딩 에이전트가 쓰는 작업 지침과 명령줄 도구입니다. 이 키트를 쓰는 에이전트는 작업을 끝냈다고 보고할 때 어떤 파일을 검사했는지, 그 파일에 프로젝트의 어떤 검사를 돌렸는지, 검사 결과가 무엇이었는지를 함께 남깁니다. 코드, 문서, 데이터, 자료 조사에 쓸 수 있고 프로그래밍 언어는 가리지 않습니다.

## 왜 만들었나

에이전트는 확인할 근거 없이 작업을 끝냈다고 보고하는 일이 많습니다. 흔한 경우는 다음과 같습니다.

- 테스트를 통과했다고 하지만, 다른 버전의 파일로 돌렸거나 아예 돌리지 않았습니다.
- 한 곳을 고치면서 이미 승인한 문서나 결과를 바꿉니다.
- 검토하는 동안 작성자가 계속 고쳐서, 실제로 나간 버전은 아무도 검토하지 않았습니다.
- 세션을 새로 열 때마다 프로젝트를 다시 설명해야 합니다.
- 한국어 문서가 번역한 글처럼 읽힙니다.

## 동작 방식

`awkit kit init`으로 키트를 넣은 뒤 에이전트에게 키트를 연결하라고 하면 됩니다. 에이전트는 프로젝트를 살펴보고, 무엇을 완료로 볼지와 결과를 누가 받는지 묻습니다. 그 답으로 한 쪽짜리 프로젝트 적용표를 쓰고, 프로젝트에 이미 있는 명령으로 검사를 설정합니다.

그 뒤로 작업은 모두 같은 순서로 진행합니다.

1. 에이전트가 목표, 고쳐도 되는 파일, 완료를 판단할 검사를 적습니다.
2. 바꾼 파일을 스냅샷으로 저장합니다. 스냅샷은 Git commit이며, 작업 중인 브랜치와 폴더는 바뀌지 않습니다.
3. 프로젝트의 별도 사본에서 스냅샷에 검사를 돌리고, 로그와 결과 파일을 해시와 함께 남깁니다.
4. 사람이 결과를 승인하면 그 결과를 채택본으로 보관하고, 이후 버전은 채택본과 비교합니다.
5. 다른 검토가 필요하면 다른 에이전트 세션이 같은 스냅샷을 검토하고, 주고받는 메시지에 그 스냅샷을 적습니다.

## 작업 종류별 절차

| 작업 | 에이전트가 하는 일 | 끝난 뒤 확인할 수 있는 것 |
|---|---|---|
| 코드 변경 | 작업을 기록하고, 변경을 스냅샷으로 저장하고, 별도 사본에서 검사를 돌립니다. | 스냅샷 ID, 검사 로그, 확인하지 못한 범위 |
| 한국어 문서 | 지켜야 할 사실을 적고, 영어로 초안을 쓴 뒤 한국어로 다시 쓰고, 사실, 문장, 구성을 따로 검토합니다. | 문서, 그리고 대조에 쓴 사실 목록 |
| 데이터 정리와 분석 | 입력 파일의 해시를 남기고, 관측값과 가정과 해석을 나눠 적습니다. | 입력까지 거슬러 확인할 수 있는 결과 파일, 데이터와 대조한 가정 |
| 자료 조사, 환경 설정 등 | 작업 유형별 지침에 따라 먼저 고정할 것, 지킬 것, 물어볼 때를 정합니다. | 결과, 출처나 근거, 빠진 부분 |
| 독립 검토 | 다른 세션이 고정한 스냅샷을 검토합니다. | 그 스냅샷에 연결된 검토 의견 |

## 시작하기

Python 3.11 이상과 Git이 필요합니다. 아직 릴리스하지 않았으므로 [pipx](https://pipx.pypa.io)로 개발 브랜치에서 설치하세요.

```sh
pipx install "git+https://github.com/min-seokkim/agent-work-kit@dev"
```

프로젝트 폴더에서 다음 명령을 실행하세요.

```sh
awkit kit init
```

그리고 에이전트에게 이렇게 말하세요.

> `agent-work-kit/README.md`를 읽고 이 프로젝트에 키트를 연결해 주세요.

예제로 먼저 써 보려면 에이전트에게 `awkit kit example data demo`를 실행하고 그 README대로 진행하라고 하세요. 예제는 열 이름 하나가 틀린 작은 데이터 프로젝트입니다. 에이전트가 검사를 돌려 실패를 확인하고, 입력을 고친 뒤 다시 검사하고, 보관한 파일을 보여 줍니다.

개발 중이며, 첫 릴리스 전까지 명령과 파일 위치가 바뀔 수 있습니다. 바뀐 내용은 [CHANGELOG.md](CHANGELOG.md)에, 개발 기록은 [docs/development.md](docs/development.md)에 있습니다.

MIT 라이선스로 배포합니다. 작성 지침의 일부는 `im-not-ai`의 자료를 고쳐 썼으며, 출처와 라이선스는 [외부 자료 고지](kit/THIRD_PARTY_NOTICES.md)에 있습니다.
