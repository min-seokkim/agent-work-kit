# Task directory

Use this directory to locate a task; its record owns the current state and next action. The selected assignment is the owner's latest recorded choice, not a live-session detector. Deferred records name the condition or decision needed to resume. Completed units retain their evidence and narrower acceptance scope; unmeasured general benefits remain open in the relevant deferred record.
