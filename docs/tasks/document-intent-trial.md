## Reported problem and scope

The owner supplied feedback from a writing project whose reviewer reported reading twelve outputs and nineteen planning, research and review documents. A topic judged absent from the finished outputs was already planned elsewhere. Editing also reportedly generalized concrete observations, weakened unsettled questions and confused reconstructed wording with the author's own words. These are reported observations; planning has not inspected that private corpus or established an awkit defect. The counts describe that feedback and do not change another writing session's separately assigned scope.

Use independently invented material. Keep the private project's drafting and editorial decisions with its writing session. Link the failure classes to existing guidance: F11 covers unsupported inferences, F29 lost context, F30 changed meaning or attribution, and F33 mistaking procedure for quality. First determine whether the agent failed to use available evidence, the handoff omitted it, or the existing records could not express it. A new coverage index or rule requires evidence of the last case or of repeated costly recovery.

Give both writers the same source and preservation requirements. Keep contexts separate, retain the intermediate English draft, and record actual model, prompt and output identities. If model or context differs, disclose that confound. A single paired example can reveal a failure and suggest a correction; it cannot establish which method is generally better.

## Evaluation and implementation decision

Fix source identities and expected distinctions before producing candidates. For P1, record the inspected scope, the evidence cited for each stage, any false absence claim and the work required to recover the planned idea. Preserve the initial partial-view answer before supplying further records. A later answer informed by more material tests recovery; it is not an independent repeat of the same task.

For P2, compare statements against the source and preservation requirements, naming the changed passage and meaning. Retain an intentionally defective control that generalizes an observation, resolves an open question, or misattributes a reconstruction. Detecting a supplied defect is separate from observing one in an actual draft. Use neutral candidate labels when reviewing paired outputs; the reviewer must disclose any prior exposure to their production. Agent judgments can identify candidate meaning changes. Actual author correction effort and acceptance remain unmeasured until a person provides them.

Report disagreements, missed defects, repeated work and unverified scope. Do not turn prose quality into a mechanical pass or use the candidate's own claims as its expected answer. A revision that fixes a failure must be checked against the same retained case. Avoid adding a standing record for every idea unless ordinary task records demonstrably cannot support the needed query.

Choose the next implementation from the result: clarify material scope or retrieval when evidence exists; repair the handoff when source status is missing; revise a guidance passage when it fails to preserve meaning; or implement a small adapter only when a repeatable missing capability remains. Public output may include synthetic cases and an execution recipe. It must distinguish a configured regression check from an actual semantic judgment and from a person's approval.

## Observed results and limits

Three fresh subagents received bounded inputs: two writers and one project-state reader. Their execution context records identify `gpt-6.1-sol` with low effort for all three. Each had one follow-up: additional project records for the reader and an affected-passage correction for each writer. These are six assigned turns, not a count of API calls. No further delegation occurred. The planner knew the production methods and constructed the source, so its comparative reading was informed, not blinded. Human editing, acceptance and a delegation advantage remain unmeasured.

The reader's first answer distinguished absence from the supplied finished drafts from unknown development elsewhere. After receiving the ordinary task record and outline, it identified the trust question as substantively planned but undrafted. Inaccessible source coverage stayed unknown, and a fixture's declared agent review was not treated as an actual independent review or author approval. The initial answer and follow-up remain separate. This small, explicitly scoped case did not reproduce a false absence claim and did not require a new coverage index; it does not establish unattended retrieval across a larger project.

Both writing methods retained the concrete observation, settled objection, unanswered question, self-counterargument and changed view. Each first draft speculated about visitors' reasoning; each writer removed a sentence during source review. The planner found further unsupported action and motive wording in the direct-Korean output and requested a scoped correction.

The shared brief itself contained a more consequential error: it turned withdrawal of a proposal to disclose all diagnostics into a new intention to select and explain diagnostics. The original source established withdrawal and continued disclosure of missing measurements, without adopting that new plan. Both writers followed the shared premise; it was already present in the English draft of that arm. Planning preserved the original brief and outputs, corrected the brief and requested one affected-pass revision in each existing thread. Reading the corrected passages confirmed removal of the new intention and the unsupported action and motive. This finding concerns source-derived handoff claims and cannot be attributed to one language method.

These were observed drafting and handoff errors. Their retained before/after passages now supply the counterexample for the guidance correction; an artificial control was not run and adds no evidence here. Source comparison and agent prose reading cover the corrected passages. Planning inspected both final essays rendered at 1200 px and 390 px using local Edge: paragraphs wrap without clipping or horizontal overflow. The manifests retain source, HTML, image and renderer identities. Neither method has demonstrated better final quality or lower author correction effort in this single pair.

The three identified worker logs report 51,798 fresh input tokens, 531,584 cached input tokens and 7,094 output tokens, with no unrecognized file or skipped line in that usage report. These totals exclude the planner and independent implementation session, and are not financial cost or API-call counts. They establish consumption for this bounded exercise, not savings from delegation.
