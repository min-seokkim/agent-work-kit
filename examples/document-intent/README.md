# Document coverage and author intent

Use these optional examples for bounded reading and writing tasks. The original routes use an invented weather-station project; the review and successive-revision route uses a fictional archive and equipment-lending room. The private writing project that prompted the work was not inspected. Prior executions and their limits are in the [task record](../../docs/tasks/document-intent-trial.md); this package supplies materials for another run.

For review or a later local edit, start with [review and successive revision](revision/README.md). Its entry supplies staged inputs, output retention and an optional historical walkthrough. The preparation below applies to the original weather-station routes.

## Prepare a run

Keep participant materials separate from [evaluator criteria](evaluator/criteria.md) and the retained [input identities and acceptance artifact](evaluator/input-identities-and-acceptance.json). Give participants only their prompt, role materials and linked current guides. A shared checkout requires an explicit reading scope; file placement alone does not restrict access. Compare input bytes against the artifact before and after a frozen checkout.

The [writer brief](writer/inputs/brief.md) contains an observed planner error, now intentionally retained for recurrence testing. It was not originally an injected control. Preserve it unchanged. The older trial's separately planned injected control was never run. Participants compare source-derived instructions with originals; explicit current owner decisions retain precedence.

## Choose a task

- Start with the [scoped reader](prompts/scoped-reader.md). Retain its answer before using the [wider reader](prompts/wider-reader.md) in the same context. Give the [coverage project](coverage/project) as its root.
- For retrieval from the outset, give the [project reader](prompts/project-reader.md) a fresh context, the same root and finished-document entry points. Supply no additional file hint or expected answer.
- Give the [writer](prompts/writer.md) its four [input files](writer/inputs). Follow current guides unless the owner explicitly assigns a comparison method. Pass exactly one selected line per fresh context:

> Draft directly in Korean for this comparison; retain the first Korean draft and source comparison.

> Retain an actual English draft, then rewrite its meaning in Korean; retain both drafts and the source comparison.

The first line is a bounded experiment authorized for this example. Both methods preserve the same source distinctions.

## Read the result

Use the evaluator criteria to inspect passages and corrections. Record mechanical integrity, agent judgments and actual human editing or approval separately in the existing task record. Keep first outputs, actual execution metadata when available and unperformed review or rendering explicit. Packaging checks establish no semantic result. A single pair establishes no preferred method, causal guide effect or cost advantage; human correction burden remains unknown without human participation.
