# Series questions

The fictional series examines how a neighbourhood weather station presents incomplete measurements. Its notes use these stable idea labels.

- OBS: What did volunteers actually check when a green display retained a stopped sensor's last value? Source U1.
- VALUE: May an interval without measurement be presented as normal? Source U2.
- TRUST: Could disclosing missing values undermine trust in the values that were measured? Source U3.
- NIGHT: What was concluded about overnight maintenance? A source catalogue mentions a discussion, but its segment is unavailable. See archive-note.md.

Labels identify questions, not completed work or approval. The project's available records may establish more than the finished reading set does.
