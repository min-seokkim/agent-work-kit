# Equipment-return source

This procedure and all roles are invented. The reader is a new desk worker at a fictional equipment-lending room.

Source requirements:

- The intake worker records the return request and time.
- The inspection worker verifies that both the equipment and its accessories have been returned.
- Only after that verification may the intake worker mark the return complete. This is permission; completion is neither mandatory nor automatic.
- If either the equipment or its accessories is missing, the request stays in the received state. Checking just one category is insufficient.
- Keep the receipt number and inspection record.
